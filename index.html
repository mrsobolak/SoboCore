Before a machine gets listed

Four things happen to every computer on this page.

  1. TestedProcessor, memory, drive, screen, keyboard, ports, battery. If something fails, it gets fixed or the machine does not get listed.
  2. Opened and cleanedDust out, case wiped down. Screws, not glue.
  3. Wiped and reinstalledThe last owner's data is erased and Windows goes back on fresh.
  4. Graded honestlyWear gets written on the listing. If it is a scuff, we call it a scuff.
  • Grade ALight wear. You have to look for it.
  • Grade BVisible wear. Works exactly the same.
  • Grade CRough outside. Cheap, and it runs.
